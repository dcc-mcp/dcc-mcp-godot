# VFX production sources

Historical design research, retained outside the executable skills. These links
are not installation requirements, runtime assets, or video-learning steps.

Mesh-fire reference: [Le Lu](https://www.youtube.com/watch?v=McRzhPV-xmc).
The implementation uses native geometry, noise, gradients and authored shaders.

## Dynamic fire research

This is an original reusable implementation informed by the public description,
chapters, and preview of [Le Lu's dynamic fire tutorial](https://www.youtube.com/watch?v=Y1ZBzIiP-v4).
The public preview shows billowing colored fires, sparks, and floor lighting.
The mage, charge, projectile, and impact form the additional casting workflow.
It is not a claim of frame-for-frame reproduction of the full video.


## Circle research


[Flex Unit's Magic Spell Circles in Blender](https://www.youtube.com/watch?v=aw28EasRtdE)
informs the circle composition. Its public preview and author description show
fantasy/science-fiction circles, emissive material, and particle work. The full
player required login during research; this implementation is not a verified
frame-for-frame copy. The
[author's texture page](https://www.patreon.com/FlexUnit/posts/magic-spell-vfx-171227220)
lists circle images, but they are not redistributed here. The default is
original procedural geometry/shading and requires no account or paid assets.

## Unbundled texture research

The [dynamic fire tutorial](https://www.youtube.com/watch?v=Y1ZBzIiP-v4)
links an [author-provided Drive folder](https://drive.google.com/drive/folders/1dJf69ivpAyGwpRo9BjJOtGusFmhPEYMS)
containing `T_fire01.png` and `T_VFX_Glow_1.PNG`. These are useful references and
optional local inputs. No redistribution license was found in that folder at
inspection, so they are not bundled in this skill. The default effect creates
its own procedural textures and is usable without those files.


Official API and asset-rights checks remain in the usage documentation.
